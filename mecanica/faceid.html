🔐 Teste de Face ID

Página de teste. Cadastre o Face ID deste aparelho e depois teste a assinatura biométrica. Nada aqui mexe nas ordens de serviço reais.

Funciona só em jusarah.com.br (domínio real, HTTPS) e num aparelho com biometria (Face ID / digital). No computador comum pode não ter biometria.

1) Cadastrar este aparelho

Dê um apelido (ex: "iPhone do Aislan") e cadastre. O celular vai pedir o Face ID / digital.

2) Testar a assinatura

Simula uma assinatura. O celular pede o Face ID; se reconhecer, valida no servidor.
