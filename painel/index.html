Cole seu token do GitHub para publicar. Ele fica salvo só neste navegador.

Primeira vez? Como criar o token (1 min):
  1. Abra github.com → novo token
  2. Em Repository access, escolha Only select repositories → jusarah-site
  3. Em Permissions → Contents, marque Read and write
  4. Clique em Generate token, copie e cole aqui
